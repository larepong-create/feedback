# ระบบความคิดเห็นลูกค้า (Customer Feedback)

ลูกค้าสแกน QR แล้วให้ดาว 1–5 และเขียนความคิดเห็น ทีมงานดูผลใน Dashboard และติดตามลูกค้าที่ขอให้ติดต่อกลับ
ระบบนี้**แยกจากระบบรายงานอุบัติการณ์** มี Google Sheets, Apps Script และหน้าเว็บของตัวเอง

## ไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `Code.gs` | โค้ดฝั่งเซิร์ฟเวอร์ วางใน Apps Script ของ Google Sheets ไฟล์ใหม่ |
| `index.html` | หน้าลูกค้า (ลิงก์ใน QR) |
| `admin.html` | หน้าทีมงาน: Dashboard รายการความคิดเห็น ติดตามลูกค้า และตั้งค่า |
| `config.js` | ใส่ลิงก์เว็บแอป Apps Script |
| `manifest.webmanifest`, `*.png` | ไอคอน |

## ขั้นตอนติดตั้ง

### 1. Google Sheets + Apps Script
1. สร้าง Google Sheets **ไฟล์ใหม่** ตั้งชื่อเช่น "Customer Feedback เมืองเอก" (อย่าใช้ไฟล์ Incident Report)
2. **ส่วนขยาย > Apps Script** ลบโค้ดเดิมทั้งหมด (`Ctrl + A` แล้ว `Delete`) วาง `Code.gs` แล้วกด `Ctrl + S`
   บรรทัดแรกต้องขึ้นต้นด้วย `/**` ไม่มี `function myFunction()`
3. เลือกฟังก์ชัน **setup** แล้วกด **Run** อนุญาตสิทธิ์
   (ถ้าขึ้น "Google hasn't verified this app" กด Advanced > Go to … (unsafe) > Allow)
   จะได้ชีต `FB_Responses`, `FB_Users`, `FB_Settings` และผู้ใช้ `admin` / `admin1234`
4. **Deploy > New deployment** > ⚙ เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL** (ลงท้าย `/exec`)

### 2. GitHub Pages
1. สร้าง repo ใหม่ชื่อ **`feedback`** ใต้บัญชี `larepong-create` (Public)
2. แก้ `config.js` ใส่ลิงก์ `/exec`
   ```js
   window.APP_API_URL = "https://script.google.com/macros/s/xxxxxxxx/exec";
   ```
3. อัปโหลดไฟล์ทั้งหมดที่ `https://github.com/larepong-create/feedback/upload` แล้วกด **Commit changes**
4. Settings > Pages > Branch `main` / `(root)` > Save รอ 1–2 นาที

### 3. ตั้งค่าในระบบ
1. เปิด `https://larepong-create.github.io/feedback/admin.html` เข้าระบบด้วย `admin` / `admin1234` แล้วเปลี่ยนรหัสผ่านทันที
2. เมนู **ตั้งค่า**
   - ช่อง **ลิงก์หน้าเว็บ** ใส่ `https://larepong-create.github.io/feedback/` แล้วกด **บันทึกการตั้งค่า**
   - ส่วน **QR สำหรับลูกค้า** มี QR ของแต่ละสาขา คลิกขวาที่ QR > บันทึกรูป เพื่อนำไปทำป้าย
   - เพิ่มผู้ใช้ให้ QA / ผู้บริหาร และหัวหน้าสาขา
3. ลองสแกน QR ส่งความคิดเห็น 1 ครั้ง แล้วดูว่าขึ้นใน Dashboard และชีต `FB_Responses`

### 4. แจ้งเตือน LINE (ไม่บังคับ)
ใช้ LINE Official Account ตัวเดิมของระบบแจ้งเหตุได้
1. ใส่ **Channel access token** ตัวเดียวกับระบบแจ้งเหตุ
2. ใส่ **Group ID**: เปิดชีต `IR_Settings` ของระบบแจ้งเหตุ คัดลอกค่าในแถว `lineTo` (ไม่ต้องเอาเครื่องหมาย `"`)
   ถ้าต้องการให้เข้ากลุ่มอื่น ให้สร้าง LINE OA ใหม่ ตั้ง Webhook เป็นลิงก์ `/exec` ของระบบนี้ แล้วเชิญบอทเข้ากลุ่ม
3. กด **บันทึกการตั้งค่า** แล้วกด **ส่งข้อความทดสอบ**

ค่าเริ่มต้นแจ้งเตือนเฉพาะ **2 ดาวหรือต่ำกว่า** และ **ลูกค้าขอให้ติดต่อกลับ** เพื่อประหยัดโควตา LINE (แพ็กเกจฟรี 300 ข้อความ/เดือน นับต่อคนในกลุ่ม)

```
⚠️ ความคิดเห็นลูกค้า
สาขาเมืองเอก
2 ดาว · ไม่พอใจ
ระยะเวลารอ
```

## การทำงาน
- **ลูกค้า**: ไม่ต้องล็อกอิน แตะดาวแล้วส่งได้เลย คำถามถัดไปเปลี่ยนตามคะแนน (4–5 ดาว ถามว่าประทับใจอะไร / 1–3 ดาว ถามว่าควรปรับปรุงอะไร) ช่องชื่อ-เบอร์ขึ้นเมื่อติ๊ก "ต้องการให้เจ้าหน้าที่ติดต่อกลับ" เท่านั้น
- **ต้องติดต่อกลับ**: ลูกค้าที่ขอให้ติดต่อกลับ หรือให้ 2 ดาวหรือต่ำกว่า เข้ารายการอัตโนมัติ ทีมงานบันทึกผลการโทรแล้วกด "ติดต่อแล้ว"
- **สิทธิ์**: ผู้บริหาร/QA เห็นทุกสาขา หัวหน้าสาขาเห็นเฉพาะสาขาตัวเอง
- **กันสแปม**: เครื่องเดียวกันส่งได้ 1 ครั้งต่อ 20 วินาที และมีช่องซ่อนกันบอท

## แก้โค้ดภายหลัง
Apps Script: วางโค้ดใหม่ > `Ctrl + S` > Deploy > Manage deployments > ✏️ > Version: **New version** > Deploy (ลิงก์ `/exec` เดิมใช้ต่อได้)
